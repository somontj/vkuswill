# VkusWill Delivery Application 🚀

Бэкенд-приложение для сервиса доставки еды и продуктов, разработанное на Java и Spring Boot. Проект представляет собой REST API для управления заказами, корзиной пользователей и каталогом товаров.

* **База данных:** [Укажите БД, например: PostgreSQL / MySQL / H2]
* **Другие инструменты:** [Например: Lombok, Liquibase/Flyway, JWT если есть]

## 🎯 Основной функционал
* **Пользователи:** Регистрация, аутентификация и разделение ролей (Клиент, Курьер, Администратор).
* **Каталог товаров:** Просмотр доступных продуктов, фильтрация по категориям.
* **Корзина и Заказы:** Добавление товаров в корзину, оформление заказа, расчет стоимости доставки и отслеживание статуса.
* **Адрей-панель:** Управление ассортиментом товаров и просмотр аналитики по заказам.

## 🚀 Как запустить проект локально

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd vkuswill
```

### 2. Настройка базы данных
Создайте локальную базу данных [Ваша БД] с именем `vkuswill`.
Откройте файл `src/main/resources/application.properties` и укажите ваши данные:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/vkuswill
spring.datasource.username=ВАШ_ЛОГИН
spring.datasource.password=ВАШ_ПАРОЛЬ
```

### 3. Сборка и запуск приложения
Используйте Maven Wrapper для сборки проекта:
```bash
# Для Windows:
mvnw.cmd spring-boot:run

# Для macOS/Linux:
./mvnw spring-boot:run
```
После запуска API будет доступно по адресу: `http://localhost:8080`

## 📑 Спецификация API (Эндпоинты)

### 🔐 Аутентификация и пользователи

| Метод | Эндпоинт             | Доступ | Описание |
| :--- |:---------------------| :--- | :--- |
| `POST` | `/api/users/register` | Все | Регистрация нового аккаунта |
| `POST` | `/api/users/login`    | Все | Аутентификация (получение токена/сессии) |
| `GET` | `/api/users/profile` | Авторизованные | Получение данных текущего профиля |

### 🍎 Каталог товаров (Продукты)

| Метод | Эндпоинт             | Доступ | Описание |
| :--- |:---------------------| :--- | :--- |
| `GET` | `/api/product`       | Все | Получить список всех доступных товаров |
| `GET` | `/api/products/{id}` | Все | Получить подробную информацию о товаре |
| `POST` | `/api/products/addProduct`     | Админ | Добавить новый товар в каталог |
| `PUT` | `/api/products/{id}` | Админ | Редактировать информацию о товаре |
| `DELETE` | `/api/products/{id}` | Админ | Удалить товар из каталога |

### 🛒 Корзина покупок

| Метод | Эндпоинт                   | Доступ | Описание |
| :--- |:---------------------------| :--- | :--- |
| `GET` | `/api/cart/cart`           | Клиент | Посмотреть текущую корзину пользователя |
| `POST` | `/api/cart/addItem`        | Клиент | Добавить товар в корзину |
| `PUT` | `/api/cart/changeQuantity` | Клиент | Изменить количество товара в корзине |
| `DELETE` | `/api/cart/delete/{Id}`    | Клиент | Удалить товар из корзины |

### 📦 Заказы и доставка

| Метод | Эндпоинт                       | Доступ | Описание |
| :--- |:-------------------------------| :--- | :--- |
| `POST` | `/api/orders/createOrder`      | Клиент | Оформить заказ (из товаров в корзине) |

### 🏪 Склад и сборка заказов (WMS)

| Метод | Эндпоинт | Доступ | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/picker/pickerRegister` | Админ / Склад | Регистрация нового сборщика (с проверкой возраста 18+) |
| `POST` | `/api/warehouse/picklist` | Сборщик | Получить/назначить следующий заказ на сборку по номеру бейджа (`?badgeNumber=...`) |
